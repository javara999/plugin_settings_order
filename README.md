# BookOasis Plugin Settings Order

BookOasis 코어 수정 없이 플러그인 설정 카드의 표시 순서와 숨김 상태를 관리하는 플러그인입니다.

## 기능

- 설정 메뉴는 `<details>`로 접힌 상태에서 시작합니다.
- 플러그인별 위·아래 이동 버튼으로 표시 순서를 변경합니다.
- `숨기기` 체크로 설정 화면에서 특정 플러그인 카드를 숨깁니다.
- 설정 저장 후 새로고침하면 동일한 순서와 숨김 상태가 적용됩니다.

## 제한

이 플러그인은 설정 화면의 DOM 표시 순서만 변경합니다. 플러그인 검색 우선순위나 백엔드 로딩 순서는 변경하지 않습니다.
