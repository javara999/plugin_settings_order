# BookOasis Plugin Settings Order

BookOasis 코어 수정 없이 플러그인 설정 카드의 표시 순서와 숨김 상태를 관리하는 플러그인입니다.

## 기능

- 별도 설정 폼 없이 플러그인 활성화만 제공합니다.
- 플러그인 설정 화면의 카드를 드래그해서 순서를 변경합니다.
- 각 카드의 숨기기 버튼으로 설정 카드를 숨길 수 있습니다.
- `plugin_settings_order` 카드 자체도 순서 변경과 숨김 대상에 포함됩니다.
- 숨긴 카드는 상단 복원 버튼으로 다시 표시할 수 있습니다.
- 변경된 순서와 숨김 상태는 BookOasis의 플러그인 설정 저장 API를 통해 유지됩니다.

## 제한

이 플러그인은 설정 화면의 DOM 표시 순서와 표시 상태만 변경합니다. 플러그인 검색 우선순위나 백엔드 로딩 순서는 변경하지 않습니다.

## Version History

- `1.1.8` - 숨김/드래그 중 남는 빈 카드 shell과 중복 카드를 자동 정리하고 드래그 대상을 실제 카드로 제한
- `1.1.7` - 플러그인 모아보기의 전역 fetch 가로채기로 설정 카드 헤더가 사라지는 충돌 우회
- `1.1.6` - 비활성화 시 숨김/순서 변경과 잔여 스타일을 즉시 해제하고 빈 카드가 남는 현상 수정
- `1.1.5` - 숨김 카드의 빈 테두리만 남는 현상을 방지하도록 인라인 표시 상태를 강제 처리
- `1.1.4` - 숨김 해제 시 원래 카드 표시 스타일을 유지하고 유효하지 않은 숨김 항목을 정리하도록 수정
- `1.1.3` - 성인도서 설정 화면에서도 순서/숨김 설정을 일반 도서 설정에 저장하도록 수정
- `1.1.2` - 숨김 카드 복원 시 코어 카드의 원래 표시 스타일을 보존하도록 수정
- `1.1.1` - `plugin_settings_order` 카드 자체도 순서 변경 및 숨김 대상에 포함
- `1.1.0` - 카드 드래그앤드롭 순서 변경, 카드 숨기기 및 복원 기능 추가
- `1.0.0` - 플러그인 설정 카드 순서/숨김 관리 플러그인 최초 릴리스
